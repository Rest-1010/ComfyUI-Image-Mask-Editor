# Image & Mask Editor

バージョン1.0.4。正式な版番号は同梱の`VERSION`ファイルに記録する。今後もフォルダ名・内部ノード名は変更せず、版番号を更新する。

## 制作の背景

AUTOMATIC1111やForgeのInpaint Sketchのように、画像へ色を描き込みながらマスクを設定する操作を、ComfyUIのノード内でも行いたいと思い、このノードを制作しました。

読み込み・生成結果のプレビューと編集画面を左右に配置し、生成した画像を編集画面へ送り直して、同じ箇所を繰り返し調整できるようにしています。色を描き込まず、マスクだけを設定することもできます。

## インストール

ComfyUIの`custom_nodes`フォルダで以下を実行し、ComfyUIを再起動してブラウザをCtrl＋F5で更新する。

```sh
git clone https://github.com/Rest-1010/ComfyUI-Image-Mask-Editor.git
```

ノード検索で`Image & Mask Editor`を追加する。Python側はComfyUIに含まれるPyTorch・NumPy・Pillowを使用する。

## 操作

- 左側の画像を読み込めない場合は壊れた画像アイコンを隠し、「画像が見つかりません。Load imageから読み込み直してください」と表示する。読み込みが成功するまでSend inpaintを無効にする。
- 保存済みの編集元・描画・マスクが見つからない場合も新規読み込みは可能。読み込めるレイヤーは復元し、欠損がある復元時は保存データを自動上書きしない。

- 左側のLoad imageアイコン、または左側の画像エリアへの画像ファイルのドラッグ＆ドロップで読み込む。複数ファイルを落とした場合は最初の画像1枚を使う。Send inpaintアイコンで右側へ送る（読み込みだけでは右側の編集内容は変更しない）。ボタン名はマウスオーバーで表示する。
- 選択カラーの横のPick colorアイコンを通常クリックすると、対応ブラウザでは周辺拡大付きの標準スポイトで画面全体から色を取得する。非対応または起動エラー時は画像内スポイトへ切り替わる。画像内スポイトでは左のプレビューまたは右の編集画像をクリックする（右のマスク表示色は取得色へ混ぜない）。もう一度押すかEscapeで解除する。独自の拡大窓はない。
- 中央の仕切りを左右にドラッグして分割比率を変更する。両側の最低幅を維持し、比率はワークフローに保存する。仕切りのダブルクリックで初期比率に戻る。フォーカス中は左右矢印キーでも調整できる。左側を大きく広げたい場合はノード自体の幅も広げる。
- 画像差し替え時も描画・マスク・Undo/Redoを維持する。解像度変更時は履歴も比例リサイズする。
- 右側はブラシ、マスクのみ、消しゴム、Undo/Redo、ホイールズーム、Shift＋左ドラッグに対応。
- 右側でShift＋ホイールを奥へ回すとブラシサイズを小さく、手前へ回すと大きくする（1〜200）。Shiftなしでは画像のズームになる。
- 右側の編集画像上で右クリックすると、その位置の色を取得して描画色に設定する。マスク表示色は混ぜない。右側の画像エリア内では右クリックメニューを表示しない。拡大鏡は出さない。左側には右クリックスポイトを割り当てない。
- Undoは触れた128×128ピクセルの区画を変更前に保存する。最大30操作、Undo/Redo合計256MiBを目安に古い履歴を削除する（最新1操作は上限を超えても保持）。広範囲の描画・全消去では戻せる回数が減る。
- 直線アイコンを選ぶと、左ドラッグの始点と終点を結ぶ直線になる。ドラッグ中はプレビュー、離すと確定。線幅はSizeで設定し、描画色・マスクのみ・消しゴムに対応。もう一度押すとフリーハンドへ戻る。
- `image`入力は任意。接続画像は実行後に左側へ表示される。Send inpaint後は右側の編集元を出力に使う。
- IMAGE/MASKを従来の生成処理へ接続する。
- 左右の下枠にそれぞれの画像の実サイズ（幅×高さ）を表示する。ズームやノードの表示サイズには影響されない。`width` / `height` のINT出力は右側のIMAGE出力の実サイズで、生成処理の幅・高さへ接続できる。
- 左側もホイールで拡大縮小、Shift＋左ドラッグで移動できる。ダブルクリックまたは新しい画像の読み込みで表示位置をリセットする。Send inpaintは拡大表示ではなく元画像を転送する。
- Send inpaintから間隔を空けたSave imageアイコンで、左側の表示画像を元の解像度のPNGとしてダウンロードできる。保存場所はブラウザのダウンロード設定に従う。右側の描画やマスクは合成しない。
- VAE DecodeのIMAGE出力を **Image & Mask Editor — Result Preview** の`image`へ接続し、`target`で編集ノードのIDを選ぶと、生成結果が左側へ戻る。編集ノードへ画像の線を戻さない。
- 編集・実行とも、このノードから画像ファイルを書き出さない。実行直前にブラウザ上の編集元・描画・マスクをPNGデータへ変換して実行入力へ直接渡し、Python側でメモリから読み込む。左側プレビューは実行に送らない。画像データをワークフローの保存用ウィジェット値へ埋め込まないため、新しい編集は実行後でも再読み込み・終了で失われる。変更前のファイル参照は読み込み可能なまま保持する。旧ワークフローを移す場合は参照先画像もコピーする。過去のファイルは自動削除しない。Undo/Redo履歴も開いている間だけ保持する。
- 実行入力は画像データを含むので、ComfyUIの実行履歴やSave ImageのPNGメタデータへ記録される場合がある。このノードのファイル書き出しを止める変更であり、ComfyUI全体の保存や履歴を無効化するものではない。
- バッチ画像の左側プレビューは先頭の画像を表示する。Send inpaint後の編集・出力はその一枚が対象。
- 内部名は`ImageMaskEditor`と`ImageMaskEditorPreview`。旧InpaintSketchノードの登録・別名は残さない。旧名のテストノードは新規配置し直す。バックアップは`ComfyUI/custom_nodes`の外に置く。

更新後はComfyUIを再起動し、ブラウザをCtrl＋F5で再読み込みする。
