# Image & Mask Editor

バージョン1.0.4。正式な版番号は同梱の`VERSION`ファイルに記録する。今後もフォルダ名・内部ノード名は変更せず、版番号を更新する。

## 制作の背景

AUTOMATIC1111やForgeのInpaint Sketchのように、画像へ色を描き込みながらマスクを設定する操作を、ComfyUIのノード内でも行いたいと思い、このノードを制作しました。

読み込み・生成結果のプレビューと編集画面を左右に配置し、生成した画像を編集画面へ送り直して、同じ箇所を繰り返し調整できるようにしています。色を描き込まず、マスクだけを設定することもできます。

## インストール

ComfyUIの`custom_nodes`フォルダで以下を実行し、ComfyUIを再起動してブラウザをCtrl＋F5で更新する。

```sh
git clone https://github.com/Rest-1010/ComfyUI-Image-Mask-Editor.git
```

ノード検索で`Image & Mask Editor`を追加する。Python側はComfyUIに含まれるPyTorch・NumPy・Pillowを使用する。

## 基本操作

1. 左側のLoad imageアイコン、または左側の画像エリアへのドラッグ＆ドロップで画像を読み込む。
2. Send inpaintアイコンを押して、画像を右側の編集画面へ送る。読み込みだけでは右側の編集内容は変わらない。
3. 右側で色を描き込む、または「マスクのみ」を選んで編集したい範囲を塗る。
4. IMAGE/MASK出力を生成処理へ接続し、ワークフローを実行する。

アイコンの名前はマウスオーバーで確認できる。

## 編集ツール・表示操作

### 描画と色の選択

- ブラシ・マスクのみ・消しゴムを切り替えて編集する。Undo/Redoで操作を戻す・やり直す。
- ブラシサイズはSizeのスライダーまたは数値入力で設定する（1〜200）。右側でShift＋ホイールを奥へ回すと小さく、手前へ回すと大きくなる。
- 直線アイコンを選び、左ドラッグで始点と終点を指定する。離すと確定し、もう一度アイコンを押すとフリーハンドに戻る。直線は描画・マスクのみ・消しゴムに対応する。
- Pick colorアイコンで色を取得する。対応ブラウザでは周辺拡大付きの標準スポイトで画面全体から取得できる。非対応または起動エラー時は画像内スポイトへ切り替わるので、左のプレビューまたは右の編集画像をクリックする。画像内スポイトはもう一度アイコンを押すかEscapeで解除する。
- 右側の編集画像上では右クリックでも色を取得できる。マスクの表示色は取得色に含めない。左側の右クリックにはスポイトを割り当てていない。

### 表示の調整と画像保存

- 左右の画像はホイールで拡大縮小、Shift＋左ドラッグで移動できる。右側のShift＋ホイールはブラシサイズ変更になる。
- 左側はダブルクリック、または新しい画像の読み込みで表示位置をリセットする。
- 中央の仕切りを左右にドラッグして分割比率を変更する。ダブルクリックで初期比率に戻り、フォーカス中は左右矢印キーでも調整できる。両側の最低幅があるため、左側を大きく広げたい場合はノード自体の幅も広げる。分割比率はワークフローに保存される。
- 左右の下枠に、それぞれの画像の実サイズ（幅×高さ）を表示する。拡大表示やノードのサイズ変更では実サイズは変わらず、Send inpaintも元の解像度で画像を転送する。
- 左側のSave imageアイコンで、プレビュー画像を元の解像度のPNGとしてダウンロードする。保存場所はブラウザの設定に従う。右側の描画やマスクは合成しない。

## ワークフローへの接続

- `image`入力は任意。接続した画像は実行後に左側へ表示される。Send inpaint後は右側の編集元をIMAGE出力に使う。
- IMAGE/MASK出力をインペイントの生成処理へ接続する。`width` / `height` のINT出力は右側のIMAGE出力の実サイズで、生成処理の幅・高さへ接続できる。
- 生成結果を左側へ戻す場合は、VAE DecodeのIMAGE出力を **Image & Mask Editor — Result Preview** の`image`へ接続し、`target`で編集ノードのIDを選ぶ。生成結果を編集ノードの入力へ直接戻す接続は避ける。

## 注意事項

### 再読み込みすると編集内容が失われる

新しい編集内容とUndo/Redo履歴は、ブラウザで開いている間だけ保持される。実行後でも、ブラウザの再読み込みや終了で失われる。ワークフローを保存しても、新しい編集元・描画・マスクは復元されない。左側のSave imageはプレビュー画像だけの保存で、編集状態の保存ではない。

- 編集・実行時に、このノードから編集用の画像ファイルを自動保存することはない。ただし、画像データがComfyUIの実行履歴やSave ImageのPNGメタデータに記録される場合はある。
- Send inpaintで画像を差し替えても、描画・マスク・Undo/Redoは維持される。解像度が変わる場合は比例リサイズされる。
- Undo/Redoは最大30操作、合計256MiBを目安とする。画像サイズや編集範囲によって戻せる回数は減る。
- 複数ファイルをドロップした場合は最初の画像1枚を読み込む。バッチ画像のプレビューも先頭の1枚で、Send inpaint後の編集・出力はその1枚が対象。
- 以前のバージョンで保存された画像参照は読み込み可能。旧ワークフローを別の環境へ移す場合は参照先画像もコピーする。過去の画像ファイルは自動削除されない。

## トラブル対処

- 「画像が見つかりません。Load imageから読み込み直してください」と表示された場合は、Load imageから画像を読み込み直す。読み込みが成功するまでSend inpaintは使えない。
- 以前保存した編集元・描画・マスクの一部が見つからない場合も、新しい画像を読み込める。復元できるレイヤーは保持される。
- ノードを更新した後は、ComfyUIを再起動し、ブラウザをCtrl＋F5で再読み込みする。バックアップは`ComfyUI/custom_nodes`の外に置く。
